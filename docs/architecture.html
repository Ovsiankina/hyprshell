4. Rules that make it cheap

  • Reactor, not game loop: block on fds, wake, mutate, draw dirty surfaces once, sleep.
  • Idle = zero GPU submissions. Animation = keep requesting frame callbacks; stop = stop requesting.
  • Shader cost = pixels × work per pixel × fps. Keep all three small, and fps at zero when idle.
  • Full-screen shaders at half/quarter res, upscaled by the compositor (wp_viewporter).
  • Animated surfaces capped at 30 fps; small widget shaders may run full rate.
  • Noise and palettes baked into textures; ASCII baked to a glyph-index texture.
  • Fullscreen / occluded / on battery / locked: daemon stops animations and pauses wallpaper apps.
  • One render pass per surface; no shell-side full-screen post pass (use Hyprland's screen shader if wanted).
